# JDBC Project

A Java application developed around direct database access using JDBC. The project focuses on relational database operations, SQL queries, data persistence, and interaction between a Java application and a database.

## Features

- Database connection and management using JDBC
- CRUD operations on relational data
- SQL query execution
- Data insertion, modification, deletion, and retrieval
- Processing of database results in Java
- Structured separation of application and database functionality

## Technologies

- Java
- JDBC
- SQL
- MySQL

## Database Operations

The application demonstrates common relational database operations, including:

- Connecting to a database
- Executing SQL statements
- Retrieving query results
- Updating database records
- Managing persistent application data

## Purpose

The project was developed to gain practical experience with relational databases and low-level database access from Java. It demonstrates the use of JDBC for communicating with a database and implementing database-backed application functionality.
